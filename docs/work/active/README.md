# Active work

Work-in-progress records live here, one file per task or branch.

Start from [`../templates/task.md`](../templates/task.md), then fill in
[`../templates/handoff.md`](../templates/handoff.md) before stopping.

Delete the record when the work is complete. If it contains a durable decision,
move that part into [`../../architecture/`](../../architecture/) or
[`../../status/known-issues.md`](../../status/known-issues.md) first. Do not
leave completed tasks here.
